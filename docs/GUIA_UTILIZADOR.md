# Guia do Utilizador

## Sistema TIBL

Este roteiro apresenta, de forma pratica e organizada, os passos para utilizar o sistema no trabalho diario. O objectivo e ajudar o utilizador a consultar informacoes, registar dados e executar tarefas sem depender de orientacao tecnica.

## Como usar este roteiro

1. Leia a introducao para entender o objectivo do sistema.
2. Use o indice para ir directamente ao modulo que deseja consultar.
3. Siga os passos pela ordem apresentada.
4. Leia com atencao as notas e avisos antes de executar operacoes sensiveis.

> Nota: Algumas opcoes podem nao aparecer no seu menu. Isso significa, na maioria dos casos, que o seu utilizador nao tem permissao para essa funcionalidade.

## Estrutura do guia

O conteudo do guia foi organizado por modulos para facilitar manutencao, revisao e reutilizacao. Cada assunto principal agora tem o seu proprio ficheiro Markdown, com prefixo numerico e agrupamento por tema.

## Observacao

Se precisar actualizar um modulo especifico, altere directamente o ficheiro correspondente no indice acima.

> Nota: Os links acima tambem sao utilizados pela versao do guia apresentada dentro do sistema.
