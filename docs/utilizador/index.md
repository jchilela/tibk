# TIBL — Plataforma de Gestão

**Guia do Utilizador**

Bem-vindo ao guia oficial do **Sistema TIBL**, a plataforma integrada de gestão da Terceira Igreja Baptista de Luanda.

Este documento foi organizado para ajudar utilizadores, líderes e equipas administrativas a executar tarefas com segurança, consistência e clareza.

---

## O que pode fazer nesta plataforma?

| Módulo | O que faz |
|---|---|
| [Membros](membros.md) | Regista e consulta os irmãos da igreja. |
| [Finanças](financas.md) | Controla caixa, banco, dízimos, ofertas e pedidos. |
| [Actividades e Escalas](actividades.md) | Gere cultos, células e escalas de serviço. |
| [Departamentos](departamentos.md) | Organiza departamentos, cargos e mandatos. |
| [Células](celulas.md) | Preenche relatórios semanais e acompanha reuniões. |
| [Património](patrimonio.md) | Regista e acompanha os bens da igreja. |
| [Comunicação](comunicacao.md) | Envia mensagens por email e SMS. |
| [Relatórios](relatorios.md) | Gera PDFs para gestão e prestação de contas. |
| [Solicitações](solicitacoes.md) | Pedidos formais entre departamentos. |
| [Painel Pastoral](pastoral.md) | Acompanhamento espiritual e pastoral da congregação. |

---

## Como aceder

1. Abra o seu browser e aceda ao endereço da plataforma
2. Introduza o seu **utilizador** e **palavra-passe**
3. Será redirecionado para o **Dashboard** com os principais indicadores
4. Use o menu lateral para entrar no módulo que pretende utilizar
5. Quando necessário, clique em **Ver**, **Editar** ou **Novo** para executar a acção correspondente

!!! warning "Sem acesso ao sistema?"
	Contacte o administrador do sistema para criar a sua conta ou rever as permissões do seu utilizador.

## Como usar este guia

1. Comece pela página do módulo que corresponde à sua função na igreja
2. Leia primeiro a secção de passos principais do módulo
3. Use as perguntas frequentes para resolver dúvidas rápidas
4. Consulte [Perfis e Permissões](perfis.md) quando uma opção não estiver visível no seu menu

!!! tip "Leitura recomendada"
	Se estiver a usar o sistema pela primeira vez, comece por **Perfis e Permissões**, depois avance para o módulo que utiliza no seu trabalho diário.

## Perfis de utilizador

Cada utilizador tem um perfil com permissões específicas.
Consulte a página [Perfis e Permissões](perfis.md) para saber o que cada perfil pode fazer.
