# Acesso ao Sistema

## Iniciar sessao

1. Abra o navegador de internet.
2. Introduza o endereco do sistema TIBL.
3. Na pagina de autenticacao, escreva o nome de utilizador.
4. Introduza a palavra-passe.
5. Clique em **Entrar no Sistema**.

Depois da autenticacao, o sistema abre o Dashboard principal.

## Terminar sessao

1. Localize o menu lateral esquerdo.
2. Desca ate ao final do menu.
3. Clique em **Terminar Sessao**.

> Aviso: Sempre que utilizar um computador partilhado, deve terminar a sessao antes de sair.

## Actualizar o perfil

1. Clique no avatar com a sua inicial no canto superior direito.
2. Abra a pagina **O Meu Perfil**.
3. Actualize os dados desejados.
4. Guarde as alteracoes.
