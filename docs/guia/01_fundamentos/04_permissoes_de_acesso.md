# Permissoes de Acesso

Nem todos os utilizadores tem acesso as mesmas funcionalidades. O que aparece no menu depende do perfil e das permissoes atribuidas.

Se uma opcao nao estiver visivel:

1. Verifique se esta na conta correcta.
2. Contacte o administrador do sistema.
3. Solicite a permissao necessaria, se aplicavel.
