# Dashboard

O Dashboard e a pagina inicial do sistema. Nele, o utilizador encontra um resumo rapido da informacao mais importante.

1. Veja os cartoes com indicadores gerais da comunidade.
2. Consulte as proximas actividades.
3. Verifique as suas escalas pessoais.
4. Acompanhe resumos financeiros, quando tiver permissao.
5. Clique em **Atualizar** para recarregar os dados.
