# Modulo de Actividades

## Consultar actividades

1. No menu lateral, clique em **Actividades**.
2. Visualize o calendario mensal apresentado na pagina.
3. Navegue entre os meses usando as opcoes do calendario.
4. Clique sobre uma actividade para consultar os detalhes.

## Criar uma actividade

1. Entre em **Actividades**.
2. Clique em **Nova Actividade**.
3. Preencha designacao, data, hora, local e responsavel.
4. Clique em **Guardar**.

## Checklists de actividade

Cada actividade pode ter checklists por departamento para organizar tarefas de preparacao.

1. Na pagina de detalhe da actividade, clique em **Checklist**.
2. Consulte o guia [Checklists](14_checklists.md) para detalhes completos.
