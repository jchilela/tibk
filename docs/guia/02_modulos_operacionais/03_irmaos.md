# Modulo de Irmaos

## Registar um novo membro

1. Clique em **Irmaos** no menu lateral.
2. Clique em **Novo Irmao**.
3. Preencha os dados pessoais.
4. Preencha os contactos e a morada.
5. Defina a celula, o estado de baptismo e outras informacoes.
6. Clique em **Guardar**.

> Aviso: O numero de telefone deve conter exactamente 9 digitos.

## Pesquisar um membro

1. Abra a pagina de **Irmaos**.
2. Use os campos de pesquisa disponiveis.
3. Introduza nome, apelido, celula ou outro criterio.
4. Clique em **Buscar**.
