# Modulo de Escalas

## Ver as suas escalas

1. No menu lateral, clique em **As Minhas Escalas**.
2. Consulte a lista das actividades em que esta escalado.
3. Verifique a data, hora e funcao atribuida.

## Criar ou actualizar escalas

1. Abra a actividade pretendida.
2. Clique em **Escalar em Massa** ou na opcao de gestao de escalas.
3. Escolha os irmaos participantes.
4. Defina a funcao de cada um.
5. Guarde as alteracoes.
