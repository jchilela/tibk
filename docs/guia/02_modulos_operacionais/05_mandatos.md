# Modulo de Mandatos

O modulo de Mandatos serve para registar os cargos ocupados pelos irmaos nos departamentos.

1. Clique em **Mandatos**.
2. Clique em **Novo Mandato**.
3. Seleccione o irmao, o departamento e o cargo.
4. Defina a data de inicio e a data de fim.
5. Clique em **Guardar**.

> Aviso: O sistema nao permite mandatos duplicados com a mesma combinacao de irmao, departamento, cargo e data inicial.
